== Description ==
BeShop is a powerful WooCommerce WordPress theme for online stores and shops. Lightweight, fast, and mobile-friendly, BeShop works perfectly with Elementor and Divi page builders. Whether you are launching an eCommerce store, a fashion shop, an electronics store, a dropshipping site, or a WooCommerce marketplace—BeShop delivers everything you need. Full RTL support, unlimited color schemes, custom layouts, and seamless WooCommerce integration make building a professional online store simple and fun. Start selling online today. 

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.
